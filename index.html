03 Embedded IoT · MERN Stack · Anomaly Detection

IoT Water Quality Monitoring Platform

An end-to-end IoT water quality monitoring platform that collects, calibrates, and processes real-time chemical and physical water measurements using ESP32 microcontrollers and a MERN stack analytics backend.

  • Hardware/Software Integration: Interfaced ESP32 microcontrollers with 16-bit ADS1115 ADCs to acquire pH, TDS, turbidity, and temperature sensor telemetry.
  • Backend Ingestion APIs: Built a Clean Architecture Node.js/Express backend supporting both X-API-Key authenticated REST ingestion (POST /api/v1/sensor/ingest) and Firebase Realtime Database listeners.
  • Water-Quality Evaluation Engine: Engineered a local statistical & rule-based evaluation engine featuring rolling-window trend analysis, threshold breach alerts, and 5-second debounce logic.
  • Real-Time Monitoring Interface: Connected a React + Vite dashboard via Socket.io and MongoDB to visualize live telemetry and acknowledge hardware alerts.
